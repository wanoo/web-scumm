Cause of the Firefox failure, reproduced in a blank page: `'\ud800'.normalize('NFC')` returns U+FFFD in Firefox and
U+D800 in Chromium (and Node, WebKit); `JSON.stringify` alone agrees everywhere. `canonicalJson`
(`src/engine/core/canonical.ts`) normalizes every string before writing it, so a string holding a lone surrogate hashes
differently in Firefox. Fixed in lot B (4.1.16 PR 2); `e2e:canonical` becomes blocking in lot F.
