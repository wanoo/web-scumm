(D12).

| # | It may not ship while… | At the tag |

| 1 | `dev`, `check`, `build` or `new-game` write a tracked file | the current game is `.cache/game`, a link (`tools/select-game.ts`); `git status` clean after `npm run dev` |

## Not done, said as such

The npm scripts are not consolidated into twelve top-level verbs (81 remain, every one in TOOLS.md); the Studio's
tabs (`rooms.ts`, `storyboard.ts`, `assets.ts`) are not split into view/state/io and have no happy-dom test per tab;
the Check tab still speaks the solver's language; `sirv-cli` stays a dependency; the handle labels of the placement
editor are unchanged. 4.1.7 does not depend on them.
