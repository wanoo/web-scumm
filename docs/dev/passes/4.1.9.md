# Passes, 4.1.9 "Gateways"

The programme's second release (§5 of `docs/dev/PLAN-4.1.8-4.1.15.md`, `docs/dev/plans/4.1.9-gateways.md`), each exit
criterion answered at the tag; then the passes only people can make (D12: reported, not blocking in 4.1.x; blocking for
4.2.0 on every surface announced as supported, D18). Every connector is `experimental` until its pass.

| # | It may not ship while… | At the tag |
|---|---|---|
| 1 | the four connectors do not pass the same contract and the same abuse tests | `tests/connectors-sdk.test.ts` (the contract on all four against a real Bridge), `tests/connectors-abuse.test.ts` (static grep, a run under `--disallow-code-generation-from-strings`, fuzz) |
| 2 | a repeated delivery produces more than one logical effect | the same proposal three times from two connectors: one sequence, `duplicate` after (contract test; `e2e:reality`) |
| 3 | a connector can execute code on the host | no `child_process`, `vm`, `eval`, `Function(` in `connectors/` (tested); SSH refuses exec, sftp, env, agent, forwarding; a virtual shell and disk |
| 4 | a game's bundle carries server code | `tools/server-code.ts` in `verify:dist`, `tests/dist-no-server-code.test.ts` |
| 5 | personal data and their retention are undocumented | `docs/en/PRIVACY.md` + fr: each datum, its duration, its deletion |
| 6 | the fourth archive does not install in an empty folder | `fresh-install` installs `web-scumm-connectors` and runs `web-scumm-connector --help` |
| 7 | the security reading's findings are open | the eight items of the second reading applied (per-address limits, one SSH session per connection, idle timeouts, IMAP TLS enforced off loopback, IMAP response caps, retryable refusals kept unseen, OB3 proof dates and suspensions) |

## Not done, said as such

Email replies (no SMTP), DKIM/SPF, IMAP STARTTLS and IDLE; RDF-canonicalised proofs and non-PEM OB2 keys; a coverage
floor and a gated mutation set for `connectors/`; the nightly fuzz not yet gated; four connector tests excluded on
Windows (said in `ci.yml`); the IMAP and MIME readers and the badge cryptography are the project's own code, tested
against scripted servers and self-made fixtures only.
