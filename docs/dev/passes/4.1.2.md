# Passes, 4.1.2 "Reliable Bridge"

The outside review of 4.1.1's Bridge, checked against the code (LOG #97): each claim that held is answered by a test
at the tag; then the passes only people can make (D12).

| # | It may not ship while… | At the tag |
|---|---|---|
| 1 | two proposals for one player can share a sequence, or a `dedupeKey` be accepted twice | one at a time per player under a lock; 100 concurrent proposals, 50 with one key, a proposal overlapping a revocation, a code confirmed twice, random interleavings (`tests/bridge.test.ts`) |
| 2 | a save's cursor can be acknowledged for a player that never applied those signals | the save is bound to its player on the first signal; a save under another link is `mismatch`, nothing applied or acknowledged; relinked on request (`tests/reality-engine.test.ts`) |
| 3 | a rotation can strand a player | what waits is signed again under the current key; a client asks for the keys once; five minutes of clock tolerance, the same in Rust (`tests/bridge.test.ts` rotation, the conformance corpus, 32 cases) |
| 4 | a stream can outlive a revoked or expired link, or a reader that stopped | closed by the Bridge on revocation, expiry and 64 KB unsent; four per player (`tests/bridge.test.ts`) |
| 5 | anyone can make the journal grow, or a bad token learn which players exist | codes in memory, 1000 at most; 60 anonymous requests and 60 failed authentications per address and minute; the token before any player (`tests/bridge.test.ts`) |
| 6 | a torn journal line keeps the Bridge from starting, or a deletion takes another player's line | the last fragment dropped and reported, any other bad line refused with its number; deletion by reading each event (`tests/bridge.test.ts`) |
| 7 | a required signal's fallback is a rule nobody plays | `fallback-unplayed` from the closed witness (`tests/reality-proof.test.ts`) |
| 8 | the Bridge's package needs TypeScript at run time, or was never installed outside the repository | one JavaScript module; `fresh-install` installs it from its tarball, runs `init`, `doctor` and `serve`, reads its keys (CI) |
| 9 | the tests of what a signal rests on are not measured | mutation set `reality`: 382 of 484 killed, 14 equivalents named, 88 missing tests listed (`docs/dev/MUTANTS.md`), the nightly runs it |
| 10 | a page can rebind its name to the Studio's port and write | the Studio answers its own names only (`tests/studio-security.test.ts`) |
