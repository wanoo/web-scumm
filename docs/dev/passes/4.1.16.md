## Not done, said as such

The mutation sets `remix` and `speedrun` exist and run (`npm run test:mutation:remix`, `test:mutation:speedrun`) but
are **measured, not gated**: 234 survivors are to be read one by one, killed or named, before 4.2 (`remix` 137:
`compile.ts` 60, `apply.ts` 50, `categories.ts` 15, `seed-code.ts` 12; `speedrun` 97: `verify.ts` 50, `recorder.ts` 40,
`envelope.ts` 7; `reality/daily.ts` has none left) (the plan's §16
lists them among the commands that must pass: that line is not met). The per-policy resume in `e2e:remix-speedrun` (the
resume is `e2e:speedrun`'s; the world binding of a resume is a unit test). The player's Mystery flow (a Mystery
category refuses to start in the player). The worker's container profile is documented, not run in CI. The Vite 8
warnings are explained, not removed. The admin bearer's failures on `/v1/runs/<id>/moderate` are not counted (the
library's `adminToken`; `serve` does not set it).
