## Known limits, said as such

- **The tag is not signed**: explicitly put off to 4.2 by D30.
- `replay-valid` proves a run consistent, not that a person played it; `inputsUsed`, the pauses and the RTA are the
  client's word (SPEEDRUN, "Trust levels").
- A printed code wheel is never seen by the verifier: such a run is `valid-unranked` until a moderator ranks it.
- The leaderboard ranks each **pseudonym**'s best: the Bridge has no player identity.
- A library host that does not pass a `SqlLimiter` counts its quota per instance; a global limit at the proxy stays
  advised.
- The worker's container profile is proved on Linux runners; the maintainer's Mac does not run Docker.
- The recorder's live RTA counts from a resume before the run's start (its sealed times are right).
- The 130 KB first-visit target for the reference is not met (137 KB, budget 140).
- `upgrade-check --from=<version>` takes a pre-release's tarball by its version without the suffix (fixed); the
  network test is one run, the forms are unit-tested.
