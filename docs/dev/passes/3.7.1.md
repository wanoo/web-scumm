# Manual passes, 3.7.1

Nothing was done by hand for 3.7.1 when it was tagged. This release changes what the archive holds (its own files,
`licenses/`) and how it is published: a pass worth making is to unpack the release's archive, serve it, and play it
offline on a phone. How to make each pass and what to bring back: `docs/en/FIELD.md`.
