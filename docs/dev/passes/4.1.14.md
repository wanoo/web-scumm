# Passes, 4.1.14 "Time Attack"

The programme's seventh release (§10 of `docs/dev/PLAN-4.1.8-4.1.15.md`, `docs/dev/plans/4.1.14-time-attack.md`), each
exit criterion answered at the tag; then the passes only people can make (D12). The leaderboard and the local tools
are `experimental` until real sessions and field tests.

| # | It may not ship while… | At the tag |
|---|---|---|
| 1 | a category needs a change of the engine | the fixture category defined in content only (`tests/speedrun-manifest.test.ts`); the reference chapter's three categories |
| 2 | an altered run is accepted | `tests/speedrun-verify.test.ts`: thirty alterations (time, action, seed, rules, signal, hash, chunk, shape, category rules), each refused with its code; `inconclusive` never ranked |
| 3 | the same replay gives different states, IGT or proofs across browsers | **Node only**: `e2e:speedrun` is written, not run, not in CI (said in the LOG); logical time uses exact arithmetic (`Math.sqrt`) |
| 4 | the clock writes the state | `core/run-clock.ts` observes; the boundary test and `tests/run-clock.test.ts`; D24 |
| 5 | a run is lost on a crash | `tests/speedrun-resume.test.ts`, `tests/dom/run-store.test.ts`: chunks written with their head in one transaction, a crash mid-write and a resume |
| 6 | the reference run does not verify | `tests/speedrun-reference.test.ts` (`reference-any.wsrun`, re-recorded on this version) and the `release.yml` step that verifies it before attaching it |
| 7 | the worker can leak a secret or hang the queue | its own process group, bounded heap and time, killed at its budget, no Bridge secret in its environment, fetch/WebSocket/TCP/UDP/DNS refused in-process (not an isolation); `tests/bridge-runs.test.ts` |

## Not done, said as such

The `server-witnessed` level; the pinned-version replay (`unsupported-version`); OS-level isolation of the worker; a
SQL `RunStore` and the `/v1/runs` mount in `bridge/src/server.ts`; `e2e:speedrun` not run here and not in `ci.yml`;
the mutation sets do not include `run-clock.ts`, `prng.ts`, `journal-chunks.ts`; `.wsrun` names and category names
untranslated; authenticated pseudonyms.
