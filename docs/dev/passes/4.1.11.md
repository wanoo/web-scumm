# Passes, 4.1.11 "Viewport"

The programme's fourth release (§7 of `docs/dev/PLAN-4.1.8-4.1.15.md`, `docs/dev/plans/4.1.11-viewport.md`), each
exit criterion answered at the tag; then the passes only people can make (D12: reported, not blocking in 4.1.x;
blocking for 4.2.0 on every surface announced as supported, D18).

| # | It may not ship while… | At the tag |
|---|---|---|
| 1 | a renderer is not replaceable behind its interface | `Renderer` with three implementations: the DOM painter, the Canvas painter, `scene/null-renderer.ts` for the tests; the equivalence test (the same clicks on the DOM and on the Canvas record the same session and journal, DPR 1/2/3, phone and desktop, reduced motion) |
| 2 | the rendering writes `GameState` | the boundary test: `src/engine/dom/render-*.ts` and the painters import neither `Engine` nor `core/players\|save` (also through `import()`); an `Intent` is the only thing a renderer sends (D21) |
| 3 | the reference scenes miss their budgets | **not measured in this lot**: `e2e:perf` on DOM and Canvas under CPU ÷4, the memory budget, a real phone; ADR 0012 says so; the pass sheet keeps the row open |
| 4 | keyboard, touch and screen reader break on either painter | the accessible buttons follow the frame's targets whatever paints the room (DOM tests); `e2e:a11y` on both painters **not run in this lot** (said in the LOG) |
| 5 | masks and layers are not editable in the Studio | `src/studio/rooms-stage.ts` (DOM test): layers, masks and zones as polygons, links by two clicks, **Save stage**; `e2e:studio` for the stage editor not run in this lot |
| 6 | the semantic journal differs on replay | `tests/journal.test.ts` and the property on 200 generated games (replay ⇒ the same journal); the dev panel and `npm run replay` consume it; an unknown kind is refused |

## Not done, said as such

The WebGL/Pixi spike (ADR 0012: Canvas 2D stays, nothing measured); every browser measure of the sheet (`e2e:perf`
on both painters, CPU ÷4 and memory budgets, DPR in a real browser, `e2e:visual`, `e2e:a11y` on both painters,
`e2e:studio` for the stage editor) beyond what the pull request's CI runs; the mutation of the new core files (read
on the next nightly); `objectiveCompleted` waits for 4.1.12.
